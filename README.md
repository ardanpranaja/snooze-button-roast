One line roasting an alarm clock that rings at 6 AM on a Saturday:

> At 6 AM on a Saturday, my alarm clock screamed like it was late for a job it doesn't even have.

## What main.ts does

`main.ts` holds the entry line as a constant, validates it against the competition gate (1–200 characters, exactly one line, not only whitespace), then writes it to `entry.txt` inside the output directory and logs the character count. The entry is 95 characters, one sentence, one line — comfortably inside the gate.

## Why this line

The alarm acts like a panicked commuter rushing to work — screaming, urgent, late — except it has no job, no boss, and nowhere to be. The reversal lands in the last few words, and the image is concrete: a little machine performing panic it has no right to feel, at 6 AM, on a Saturday, in your bedroom.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry to `out/entry.txt`.
